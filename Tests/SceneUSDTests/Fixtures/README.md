# USDZ fixture

`reference.usdz` is generated by `python3 generate.py` using Python's standard-library
ZIP writer. It contains an original minimal USDA layer and a 1×1 PNG, with uncompressed
member data aligned to 64 bytes. The script verifies CRCs and alignment after writing.

The fixture provides an independent input for the pure-Swift reader. No downloaded
model assets or OpenUSD binaries are required to run the tests.
