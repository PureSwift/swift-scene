# USDZ fixture

`reference.usdz` is generated by `python3 generate.py` using Python's standard-library
ZIP writer. It contains an original minimal USDA layer and a 1×1 PNG, with uncompressed
member data aligned to 64 bytes. The script verifies CRCs and alignment after writing.

The fixture provides an independent input for the pure-Swift reader. No downloaded
model assets or OpenUSD binaries are required to run the tests.

# USDA

`triangle.usda` is an original test scene with a translated Xform, triangle mesh, Material,
relationship, asset path, typed layer dictionary, and absent/blocked property values.
It was validated and serialized by OpenUSD 26.11 (`Usd.Stage.Open`, `UsdGeom.Mesh`, and
`Sdf.Layer.Export`). The Swift tests read that serialized output. OpenUSD is not required
to build the package or run the tests.

# Preview Surface

`preview-surface.usda` was authored with OpenUSD 26.11's Python API. It contains one
triangle and a bound constant Preview Surface shader with diffuse color (0.25, 0.5,
0.75), metallic 0.5 and roughness 0.25. `UsdShade.MaterialBindingAPI.Apply` authors
the usual `prepend apiSchemas` metadata. Tests load it and round-trip through USDZ;
running tests does not require OpenUSD.
